# AI 面试高频手写代码速查（静态版）

本仓库包含一个可直接部署到 GitHub Pages 的静态页面（纯 HTML/CSS/JS），用于展示 AI 面试高频手写代码与知识点概览。

## 本地预览

直接用浏览器打开 `index.html` 即可。

## GitHub Pages 部署

1. 确保仓库根目录包含 `index.html`、`styles.css`、`script.js`。
2. 在 GitHub 仓库 Settings → Pages 中选择 “main / root”。
3. 保存后等待构建完成，访问生成的 Pages 链接。

## 原始 Notebook（可选）

如果需要完整的 Jupyter Notebook 版本，可参考 `interview_ai_notebook.ipynb`。
